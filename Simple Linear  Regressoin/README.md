# Simple Linear Regression: House Price Prediction

This project uses Simple Linear Regression to predict house prices in Tehran based on house area.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

Project Overview

The goal of this project is to understand and implement a basic machine learning regression model. The model learns the relationship between house area and price using a dataset of Tehran housing prices.

Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
